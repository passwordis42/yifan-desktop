# 一翻

Windows 桌面版 v0.1.0。在任意软件里选中文字，按全局热键翻译；也可以框选屏幕做截图识译。

翻译、厂商、术语本和额度规则移植自 [chrome-llm-translate](https://github.com/passwordis42/chrome-llm-translate) `v0.1.14`（`main`，`174d4f6`）。这是另一个产品：不包一层浏览器，也不和扩展互相同步。

## 能做什么

- 托盘常驻。关掉主窗口只是回到托盘，热键仍然有效。托盘可以打开主窗口、开始截图识译、开关翻译服务、退出。
- 总开关默认开。关掉以后，划词和截图两枚热键都不触发，已保存的设置和 Key 还在。
- 划词翻译默认 `Alt+E`。优先读前台窗口里选中的文字；读不到再短暂模拟复制，用完把原来的剪贴板放回去。超过 5000 字只在本地提示缩短，不发请求。两边都没有文字时提示「没有选中文字，也读不到剪贴板。」受保护或权限不够的窗口直接说明读不到，不会假翻，也不会偷偷改用别的厂商。
- 划词浮层置顶、流式出译文。短文高度跟着内容走，长文停在工作区留边以内，正文在窗里滚动，底部「复制译文 / 改语言 / 关闭」钉住。标题栏可拖，松手留在可见屏幕里。可以一键放大到约 640 宽（高度为工作区减边距），再还原。只改窗口，不改字号（原文 13、译文 15）。没有边角缩放，没有 A−/A+。位置、大小、放大状态不记住。
- 截图识译默认 `Alt+S`，主窗口和托盘也能进。框选时先在内存里留一帧屏幕；Esc、点空白或「取消」会丢掉这帧，不上传、不写盘。当前厂商没有视觉模型时，入口写明「当前厂商不支持截图识译」，不会静默失败，也不会换成另一家。
- 识译结果窗：加载中不能拖、不能改大小、不能改字号、不能放大。出结果（成功或失败）后可以拖标题栏，悬停边角才出现把手，A−/A+ 只改本窗字号（12–22，默认 13），一键放大只把宽度改到约 560。这些都不写入磁盘。
- 五家厂商分槽：千问（百炼）、OpenAI、火山引擎、DeepSeek、Kimi。没有自定义 Base URL，不收云厂商 AK/SK。火山引擎要填模型名或方舟接入点 `ep-…`。DeepSeek / Kimi 查账户余额，失败就标明已改为本地估算；另外三家只显示估算，并标「估算」。
- 术语本命中优先。源语言、目标语言和扩展相同。两枚热键可改、可恢复默认，互不冲突，保存后马上生效。主页显示实际生效的键。
- 开机启动默认关。单实例。日志和未处理异常从第一天就写到本机。不自动安装更新。

## 不做

整页翻译、应用内浏览器、各软件右键菜单、强制可划选、网页拐角手势、macOS / Linux / 手机、和 Chrome 扩展同步、自定义 Base URL、云 AK/SK、翻译历史、划词窗边角缩放和 A±、打开窗口就自动翻译。

## 环境

在 **Windows 10 1809（17763）或 Windows 11，x64** 上编译和运行。需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。发布包自带 Windows App SDK 运行时，开发机如果直接 `dotnet run`，还需要能还原 NuGet 上的 Windows App SDK 1.7。

不需要管理员权限。不要在未同意的电脑上安装或运行。

这套代码在 Linux 上只能编译和运行 `Yifan.Core` 的单元测试。WinUI 3 工程必须在 Windows 上编。

## 开发机上跑

```powershell
dotnet test .\tests\Yifan.Core.Tests\Yifan.Core.Tests.csproj
dotnet run --project .\src\Yifan.App\Yifan.App.csproj -c Debug -p:Platform=x64
```

开机启动写的是当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Yifan`，值是 `"完整路径\Yifan.exe" --tray`。`--tray` 只进托盘，不打开主窗口。

## 打包

在 Windows 上：

```powershell
powershell -ExecutionPolicy Bypass -File .\packaging\pack.ps1
```

产物是 `dist\Yifan-0.1.0-win-x64.zip`。解压后运行里面的 `Yifan.exe`。这是免安装的自包含目录，适合放到 GitHub Release。脚本不会把程序装到别的电脑上。

## 设置放在哪

只放在当前用户的 `%AppData%\Yifan\`：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 总开关、开机启动、五家 Key 和模型、语言、热键、术语本 |
| `usage.json` | 本机估算用量，和设置分开，避免改语言时把累计估算冲掉 |
| `logs\yifan.log` | 启动、失败和未处理异常。不记录选中文字、译文或完整 Key |

程序拒绝把这些文件写到 exe 旁边。API Key 只留给你配置的当前厂商，本版没有自建后端，也没有翻译历史。

## 权限，以及为什么要

| 能力 | 原因 |
| --- | --- |
| 全局热键 `RegisterHotKey` | 在别的软件里按划词键和截图键 |
| UI Automation | 读前台窗口里已经选中的文字 |
| 剪贴板 | 界面读不到选区时，短暂模拟复制再还原 |
| 屏幕截图 | 只为这一次框选识译。取消则丢弃内存中的画面 |
| 低级键盘钩子 | **只在设置里改热键的那几秒**安装，收到按键或取消后立刻卸掉。平时不挂钩子 |
| 当前用户的「运行」注册表项 | 只有打开「开机启动」才写。默认不写 |
| 置顶窗口 | 划词浮层和识译结果要压在其他窗口上面 |

没有提权。读不到受保护窗口时，用中文说明，不强行提升权限。

## 日志和崩溃

进程级未处理异常、界面线程异常、以及没人观察的任务异常都会记到 `%AppData%\Yifan\logs\yifan.log`。界面线程上会弹出「这次操作没有完成……不会假翻。」单实例用本地互斥体 `Local\Yifan.Desktop.v0.1`；第二个进程只会请第一个把主窗口打开。

## 已知限制

云端 Linux 环境不能编译 WinUI 3，也不能做热键、UIA、截图和托盘的真机验证。下面这些要在 Windows 上按测试计划走一遍：

- 不同软件暴露选区的能力不一样。记事本、Word 通常可以；读不到就走剪贴板。受保护或更高完整性级别的窗口会诚实失败。
- 剪贴板还原覆盖文本，以及能以全局内存读出来的格式。个别特殊格式可能还原不完整。
- 框选用的是开始时留在内存里的一帧，不是透明镂空层。取消不会上传。受保护的画面可能是黑的，识译会说没有文字或截不到，不会编一句译文。
- 多显示器、不同缩放比例下，浮层会尽量落在可见工作区内。混合 DPI 的像素换算需要在真机上看一眼。
- 热键如果被系统或其他软件占用，`RegisterHotKey` 会失败。主页仍显示你设置的键，并提示可能被占用，不会写成「未设置」。
- DeepSeek / Kimi 的余额接口以厂商当时的返回为准；失败就降级成标明过的本地估算。估算不是账单。
- 本版不检查、不下载、不安装更新。

## Windows 测试计划

1. 启动后看托盘。关掉主窗口，进程还在。再从托盘打开主窗口，并从托盘退出，进程结束。
2. 在记事本选中一段英文，按 `Alt+E`。浮层置顶，原文是选中内容，译文一段段出现。复制译文、改语言会重翻，关闭后热键还能再开。
3. 短句浮层不要撑满屏幕。贴一段仍在 5000 字以内的长文：默认高度不超过工作区，正文能滚完，底部三个按钮还在。拖标题栏，松手仍在屏幕内。放大后字号不变，还原回到这次的默认大小。拖边角不改变大小，没有 A±。关掉再按热键，位置和放大状态回到默认。
4. 译文还没出完时就能拖、能放大。不选字并且先清空剪贴板，再按热键：出现「没有选中文字，也读不到剪贴板。」不出现假译文。选中超过 5000 字：本地提示缩短，抓包或断网时也不该发出翻译请求。模拟复制之后，原来的剪贴板内容还在。
5. 按 `Alt+S` 框选记事本或别的窗口。Esc 或点空白取消后，没有新的网络请求。确认后先看到「正在识字…」，这时不能拖、不能改大小、没有 A± 和放大。出结果后可以拖，鼠标移到边上才看到把手，拖边角能改大小，A± 只改字号，放大只改窗口。关掉再开，这些都回到默认。把当前厂商改成 DeepSeek 或 Kimi：主页和热键都明确说不支持截图识译，厂商不会被悄悄换掉。
6. 五家分别保存不同的 Key。来回切换，Key 不互相覆盖。额度行：DeepSeek / Kimi 是余额或写明降级的估算；千问 / OpenAI / 火山标着「估算」。术语本里的固定译法会原样出现在译文里。Key 留空、断网、401、402 都是中文说明，没有假译文。
7. 把两枚热键改成别的组合，立刻能用。设成同一个键会被拒绝。恢复默认回到 `Alt+E` / `Alt+S`。关掉总开关后两个热键都没反应，再打开又恢复，Key 还在。
8. 主窗口、托盘、设置里都没有整页翻译、右键菜单、强制可划选、拐角手势。开机启动默认是关的。

## 方案

- `src/Yifan.Core`：不依赖 WinUI 的服务层。厂商、设置分槽、术语本、提示词、SSE、额度、划词/识译窗口几何都在这里，和扩展的行为对齐。
- `tests/Yifan.Core.Tests`：xUnit。Linux 上跑过。
- `src/Yifan.App`：WinUI 3 非打包应用。托盘、热键、UIA、剪贴板、截图、主窗口和两块浮层。

界面按已确认的 v0.1.0 稿：浅色，纸色内容（`#f4f1ea` / `#fffefb` / `#2c2a26` / `#2f6fed`）配 Fluent 窗口。划词和识译标题栏用平底 `#fbfaf6`。正文是左侧细线原文加粗译文，不是稿里的对照卡片。拖动稿上的虚线原位置不是功能。
